ข้อ 22parameter ของ transfer learning
โหลด VGG16 include_top=False input 224×224×3 แล้วต่อ Flatten → Dense(128, relu) → Dense(3, softmax) และตั้ง conv_base.trainable = False เขียน trainable, non-trainable และ total parameter พร้อมวิธีคิด

Dense(128): 25,088·128 + 128 = 3,211,392 · Dense(3): 128·3 + 3 = 387 · trainable = 3,211,779

non-trainable = 14,714,688 เพราะ freeze ทั้ง conv base · total = 17,926,467

ข้อ 23residual block กับ vanishing gradient
อธิบายว่าทำไม network ธรรมดาที่ลึก 50 ชั้นเทรนยาก และ residual block แก้ได้อย่างไร ใช้สมการ h(x) = f(x) + x และตัวเลขประกอบ

backprop คูณ gradient ย้อนทีละชั้น ถ้าตัวคูณแต่ละชั้นราว 0.8 ห้าสิบชั้นได้ 0.8⁵⁰ ≈ 0.000014 layer ต้นแทบไม่ถูกอัปเดต

residual block ให้ h(x) = f(x) + x จึงได้ ∂h/∂x = ∂f/∂x + 1 ถ้า ∂f/∂x = 0.01 ก็ยังส่งต่อ 1.01 gradient มีทางลัดผ่าน skip connection

อีกข้อคือถ้า weight เป็น 0 บล็อกกลายเป็น identity h(x) = x การเพิ่มบล็อกจึงไม่ทำให้แย่ลง

ข้อ 24เลือกแนวทาง transfer learning
มีภาพรถยนต์ 200,000 ภาพแยก 50 รุ่น และภาพใบไม้เป็นโรค 300 ภาพแยก 4 โรค ทั้งสองงานใช้ ResNet ที่เทรนบน ImageNet ควรใช้ scenario ใดและตั้ง learning rate อย่างไร

รถยนต์: ข้อมูลมาก + domain คล้าย ImageNet คือ scenario #2 fine tune ส่วนท้าย freeze ราว 60%–80%

ใบไม้เป็นโรค: ข้อมูลน้อย + domain ต่าง คือ scenario #3 fine tune จาก activation ช่วงต้น freeze ราว 33%–50%

ทั้งสองงานใช้ learning rate เล็กกว่าการเทรนปกติ ฝึก head ใหม่ก่อนสองสาม epoch แล้วค่อยปลดล็อก compile ใหม่ และลด learning rate อีก
