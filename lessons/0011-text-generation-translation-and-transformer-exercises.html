ข้อเขียน

ข้อ 17scaled dot-product attention ด้วยมือ
q = [1, 0, 1, 0] k₁ = [1, 0, 1, 0] k₂ = [0, 1, 0, 1] v₁ = [4, 0] v₂ = [0, 4] คำนวณ attention output ทีละขั้น และบอกผลถ้าไม่ scale

dot product: q·k₁ = 2 · q·k₂ = 0 · d_k = 4 หาร √4 = 2 ได้ [1, 0]

softmax: e¹ = 2.718 e⁰ = 1 รวม 3.718 ได้ [0.731, 0.269] · output = 0.731[4, 0] + 0.269[0, 4] = [2.92, 1.08]

ไม่ scale: softmax([2, 0]) = [0.881, 0.119] output [3.52, 0.48] แหลมกว่า เมื่อ d_k ใหญ่ softmax จะอิ่มตัวและ gradient หาย

ข้อ 18teacher forcing กับ inference
อธิบายว่า decoder ได้ input อะไรตอนเทรนและตอนใช้งาน ใช้ประโยค [start] I like cats [end] และบอกว่าโค้ด spa[:, :-1] กับ spa[:, 1:] เกี่ยวข้องอย่างไร

ตอนเทรน decoder input = [start] I like cats · target = I like cats [end] เหลื่อม 1 ตำแหน่ง ป้อนคำจริงทุก step เรียก teacher forcing คำนวณทุก step พร้อมกันได้

spa[:, :-1] ตัด token สุดท้ายได้ decoder input · spa[:, 1:] ตัด token แรกได้ target · ฝั่งปลายทางจึงตั้ง output_sequence_length = sequence_length + 1

ตอนใช้งานไม่มีประโยคปลายทาง ป้อน [start] แล้วเอาคำที่ทายได้ป้อนกลับทีละ step จนได้ [end] ถ้าทายผิดต้นทาง ความผิดจะติดไปทุก step

ข้อ 19BLEU
ประโยคเป้าหมาย "the cat is on the mat" ประโยคที่ทาย "the cat on the mat" คำนวณ p₁ และ p₂ แล้วบอกว่า brevity penalty มีผลอย่างไร

p₁: ทายมี 5 คำ the, cat, on, the, mat ตรงทั้ง 5 ได้ 5/5 = 1

p₂: bigram ที่ทาย the cat, cat on, on the, the mat มี 4 ตรง the cat, on the, the mat ได้ 3/4 = 0.75

c = 5 ≤ r = 6 จึง BP = e^(1 − 6/5) = e^(−0.2) ≈ 0.819 คะแนนถูกลดเพราะคำแปลสั้นกว่าเป้าหมาย
