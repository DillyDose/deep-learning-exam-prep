แบบฝึก Lesson 12: Transfer Learning และ Transformers สำหรับ NLP

ข้อเลือกตอบ 16 ข้อ กดแล้วเห็นผลและเหตุผลของทุกตัวเลือกทันที ข้อคำนวณทุกข้อทำได้ด้วยมือโดยไม่ใช้เครื่องคิดเลข ส่วนข้อเขียน 3 ข้อให้ลองเขียนก่อนแล้วจึงกดดูเฉลย

ข้อเลือกตอบ

ข้อ 1Hugging Face libraries
ทีมหนึ่งใช้ Hugging Face และต้องการคำนวณ macro F1 ของโมเดลบน test set ควรใช้ library ใด และข้อใดถูกเกี่ยวกับ tokenizer?
ข้อ 2NER
ใช้ pipeline("ner", aggregation_strategy="simple") กับข้อความ "We met Tim Cook in Paris" ข้อใดอธิบายผลของ aggregation_strategy="simple" ได้ถูกต้อง?
ข้อ 3Extractive QA
ระบบ extractive question answering ได้ context "The battery lasts ten hours but the screen is dim." และคำถาม "How long does the battery last?" ข้อใดเป็นคำตอบที่ระบบชนิดนี้สามารถคืนได้?
ข้อ 4Cross-attention shape
ใช้ T5 แปลประโยคต้นทางยาว 7 token เป็นประโยคปลายทางยาว 9 token โดย batch size 1 และแต่ละ layer มี 8 heads ข้อใดคือ shape ของ outputs.cross_attentions[0]?
ข้อ 5Approaches
บริษัทมีคู่มือภายในที่แก้ไขทุกสัปดาห์ และต้องการให้ generative model ตอบคำถามพนักงานจากคู่มือฉบับล่าสุดโดยไม่ต้องเทรนโมเดลใหม่ทุกครั้งที่คู่มือเปลี่ยน วิธีใดเหมาะที่สุด?
ข้อ 6LoRA parameters
ใช้ LoRA rank r = 4 กับ weight matrix ขนาด 1024 × 1024 หนึ่งตัว จำนวน trainable parameter ของ LoRA สำหรับ matrix นี้คือเท่าใด?
ข้อ 7LoRA formula
Linear layer ที่ใช้ LoRA โดย lora_alpha = 32 และ r = 8 ข้อใดคือ output ของ layer นี้ตอนเทรน?
ข้อ 8LoRA target modules
ใน LoraConfig ที่ตั้ง target_modules=["q_lin", "v_lin"] และ modules_to_save=["pre_classifier", "classifier"] กับ DistilBERT ข้อใดถูกต้อง?
ข้อ 9RAG similarity
ระบบ RAG ค้นเอกสารให้คำถามหนึ่งได้ cosine similarity สูงสุด 0.92 แต่คำตอบที่ generator สร้างผิด ข้อใดอธิบายได้ถูกต้องที่สุด?
ข้อ 10Imbalanced metric
Dataset 3 คลาสมีสัดส่วน 80%, 15%, 5% และโมเดลทายคลาสแรกทุกข้อ ข้อใดคือ accuracy และ macro F1 ของโมเดลนี้โดยประมาณ?
ข้อ 11Tokenizer
Tokenizer ของ distilbert-base-uncased แปลงประโยค "I love NLP" เป็น ['[CLS]', 'i', 'love', 'nl', '##p', '[SEP]'] ข้อใดถูกต้อง?
ข้อ 12Padding
Tokenize batch ที่มีสองข้อความยาว 5 และ 8 token (นับ [CLS] และ [SEP] แล้ว) ด้วย padding=True ข้อใดคือ attention_mask ของข้อความแรก?
ข้อ 13Hidden state shape
ป้อน batch ของ 8 ประโยคที่ pad ให้ยาว 20 token เข้า DistilBERT (hidden_dim 768) แล้วใช้ outputs.last_hidden_state[:, 0] ผลมี shape เท่าใดและเป็น vector ของอะไร?
ข้อ 14Feature extraction vs fine-tuning
ข้อใดเปรียบเทียบ feature extraction กับ fine-tuning ของ DistilBERT ได้ถูกต้อง?
ข้อ 15Classification head
ต้องการจำแนก tweet เป็น 4 คลาสด้วย AutoModelForSequenceClassification บน checkpoint ที่ hidden size 768 และ head เป็น Linear ชั้นเดียว Linear ชั้นนี้มี parameter กี่ตัว?
ข้อ 16Architectures
ข้อใดจับคู่ชนิดของ Transformer กับโมเดลและงานได้ถูกต้องทั้งหมด?

ข้อเขียน

ข้อ 17LoRA กับ full fine-tuning
โมเดล encoder 12 layer d_model = 768 ใส่ LoRA r = 16 ที่ q และ v ทุก layer head ใหม่คือ Dense 768 → 3 คำนวณ trainable parameter และอธิบายว่าทำไมเวลาเทรนไม่ลดตามสัดส่วน

LoRA ต่อ matrix: 16 × 768 + 768 × 16 = 24,576 · 12 layer × 2 matrix = 24 matrix ได้ 589,824

head: 768 × 3 + 3 = 2,307 · trainable รวม 592,131

forward และ backward ยังต้องผ่านทั้งโมเดล เวลาจึงลดไม่มาก สิ่งที่ประหยัดคือ memory ของ optimizer และพื้นที่เก็บ adapter ต่องาน

ข้อ 18feature extraction กับ fine-tuning
เทียบสองวิธีใน workshop DistilBERT: อะไรถูกเทรน ใช้ hidden state ตัวไหน classifier เป็นอะไร และผลต่างกันเพราะอะไร

feature extraction: ล็อก DistilBERT ทั้ง body ดึง last_hidden_state[:, 0] คือ [CLS] 768 ค่าต่อข้อความ แล้วเทรน logistic regression ภายนอก val acc 0.635 macro F1 0.531

fine-tuning: AutoModelForSequenceClassification(num_labels=6) เทรนทั้ง 66,958,086 parameter head ต้อง differentiable gradient ย้อนเข้า encoder test acc 0.9235 macro F1 0.8754

fine-tuning ดีกว่าเพราะ hidden state ถูกปรับให้แยกอารมณ์ได้ ส่วน feature ที่ล็อกไว้มาจากการ pretrain ทาย [MASK] ซึ่งไม่ได้ตั้งใจแยกอารมณ์ คลาสเล็กอย่าง love และ surprise จึงอ่อน

ข้อ 19accuracy กับ macro F1
dataset 3 คลาส มี 900, 80, 20 ตัวอย่าง โมเดลทายคลาสแรกทุกข้อ คำนวณ accuracy และ macro F1 แล้วบอกว่าควรใช้ metric ไหนเลือกโมเดล

accuracy = 900/1,000 = 0.90

คลาสแรก precision 0.9 recall 1 F1 = 2 × 0.9 × 1/1.9 ≈ 0.947 · อีกสองคลาส F1 = 0 · macro F1 = 0.947/3 ≈ 0.316

ข้อมูลไม่สมดุลแบบนี้ accuracy หลอกได้ ควรใช้ macro F1 ซึ่งให้น้ำหนักทุกคลาสเท่ากัน แบบที่ workshop emotion ใช้
