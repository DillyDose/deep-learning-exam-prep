Backpropagation: คำนวณ Gradient ย้อนกลับด้วย Chain Rule

นี่คือหัวใจของข้อสอบวิชานี้ สไลด์ของบทนี้ตั้งใจเว้น "คำตอบตัวเลข" ของตัวอย่างคำนวณไว้ให้กรอกในคาบ (มีแค่ diagram กับสูตรทั่วไป) — บทเรียนนี้จะคำนวณให้ครบทุกตัวเลขที่สไลด์เว้นไว้ พร้อมพิสูจน์ที่มาของสูตร δ ทุกขั้น.

1. Chain Rule: เครื่องมือเดียวที่ใช้พิสูจน์ backprop ทั้งหมด

Chain Rule คือการหาอนุพันธ์ของ "ฟังก์ชันซ้อนฟังก์ชัน" — ถ้า y=f(u) และ u=g(x) แล้ว dy/dx = (dy/du)·(du/dx) สไลด์ทิ้งคำถามไว้ 2 ข้อให้ฝึกมือก่อนเข้า backprop จริง:

แก้เอง: y = e^(x³) ให้ u = x³ ดังนั้น y = e^u — dy/du = e^u = e^(x³) และ du/dx = 3x² รวมด้วย chain rule: dy/dx = e^(x³) · 3x².

สังเกตแพทเทิร์น: "คงฟังก์ชันชั้นนอกไว้ทั้งดุ้น (e^(x³)) แล้วคูณด้วยอนุพันธ์ของชั้นใน (3x²)" — นี่คือกลไกเดียวกันที่จะใช้แยก ∂J/∂θ ทีละชั้นในเครือข่าย.

แก้เอง: ตาม hint ให้ u=2x−5 ดังนั้น y=u¹⁰ — dy/du = 10u⁹ และ du/dx = 2 รวมกัน: dy/dx = 10u⁹ · 2 = 20(2x−5)⁹.

สไลด์เรียกภาพนี้ว่า "Computation Graph": มองเป็นสองขั้นเรียงต่อกัน (x → u → y) แต่ละขั้นมีอนุพันธ์ของตัวเอง แล้ว "คูณไล่ตามลูกโซ่" กลับมาที่ x.

โครงข่ายประสาทเทียมก็คือ computation graph ที่มีขั้นมากกว่านี้ (z[1]→a[1]→z[2]→a[2]→…) แค่นั้นเอง.

2. จาก Chain Rule สู่ ∂J/∂θ: สูตรทั่วไปของ Backprop

โครงข่าย 2 layer คือฟังก์ชันซ้อนฟังก์ชัน: h(x) = g(θ[2]·g(θ[1]·x)).

  • การหา ∂J/∂θ[2] (layer สุดท้าย) ใช้ chain rule 1 ขั้น: ∂J/∂θ[2] = (∂J/∂z[2])·(∂z[2]/∂θ[2])
  • การหา ∂J/∂θ[1] (layer แรก) ต้องไล่ผ่าน 2 ขั้น เพราะ θ[1] ส่งผลถึง J โดยทางผ่าน z[1]→a[1]→z[2]→a[2]→J: ∂J/∂θ[1] = (∂J/∂z[2])·(∂z[2]/∂a[1])·(∂a[1]/∂z[1])·(∂z[1]/∂θ[1])

นี่คือเหตุผลที่ยิ่ง layer อยู่ลึกเท่าไหร่ (ใกล้ input) โซ่การคูณยิ่งยาวขึ้นเท่านั้น.

ก่อนไปข้างหลัง (backward) ต้องไปข้างหน้า (forward) ให้ครบก่อนเสมอ: h_θ(x) = a₁⁽²⁾ = g(z₁⁽²⁾) โดย z₁⁽²⁾ = θ₁₀⁽²⁾+θ₁₁⁽²⁾a₁⁽¹⁾+θ₁₂⁽²⁾a₂⁽¹⁾+θ₁₃⁽²⁾a₃⁽¹⁾.

สูตรนี้เหมือนที่เรียนใน Lesson 2 หัวข้อ 8 ทุกตัวอักษร เพียงแต่ตอนนี้จะใช้ค่าที่คำนวณได้นี้ไปหา error ย้อนกลับ.

สไลด์นิยาม δⱼ⁽ˡ⁾ = ∂J/∂zⱼ⁽ˡ⁾ ("error" ที่ node j ในเลเยอร์ l มีต่อ cost) แล้วให้สูตรสำเร็จ 2 บรรทัดที่ต้องพิสูจน์ที่มา (หัวข้อ 3):

  • สำหรับ output layer: δ₁⁽²⁾ = h(x) − y (ง่ายที่สุด เพราะเป็น layer สุดท้ายที่เทียบกับ y ตรงๆ)
  • สำหรับ hidden layer: δⱼ⁽¹⁾ = (θⱼ₁⁽²⁾)ᵗ · δ₁⁽²⁾ · g'(zⱼ⁽¹⁾) — δ ของ layer ก่อน "ยืม" ค่า δ ของ layer ถัดไปมาคูณกับ weight ที่เชื่อมสองเลเยอร์ (θ) และคูณด้วยอนุพันธ์ของ activation function ที่ node นั้น (g')

นี่คือที่มาของคำว่า "back-propagate": error ไหลจากขวา (output) ไปซ้าย (input) สวนทางกับ forward pass เป๊ะ.

นี่คือการพิสูจน์ที่ต้องตามให้ทันทุกขั้น.

ขั้นที่ 1 (θ[2]): ∂J/∂θ[2] = (∂J/∂z[2])·(∂z[2]/∂θ[2])

  • เทอมแรก ∂J/∂z[2] = h(x)−y (มาจาก cross-entropy loss ผสม sigmoid ที่ลดรูปสวยแบบที่เห็นใน Lesson 1 หัวข้อ 6)
  • เทอมสอง ∂z[2]/∂θ[2] = a[1] (เพราะ z[2]=θ[2]·a[1] อนุพันธ์เทียบ θ[2] เหลือ a[1])

รวมกันได้ ∂J/∂θ[2] = (h(x)−y)·a[1].

ขั้นที่ 2 (θ[1], โซ่ยาวกว่า): ∂J/∂θ[1] = (∂J/∂z[2])·(∂z[2]/∂a[1])·(∂a[1]/∂z[1])·(∂z[1]/∂θ[1]) แทนแต่ละเทอม:

  • ∂J/∂z[2]=h(x)−y
  • ∂z[2]/∂a[1]=θ[2] (เพราะ z[2]=θ[2]·a[1])
  • ∂a[1]/∂z[1]=g'(z[1])=a[1](1−a[1]) (อนุพันธ์ sigmoid ที่พิสูจน์ในหัวข้อ 5)
  • ∂z[1]/∂θ[1]=x

รวมกันทั้ง 4 เทอม: ∂J/∂θ[1] = (h(x)−y)·θ[2]·a[1](1−a[1])·x.

สังเกตว่าสูตรนี้มี "4 ตัวคูณ" พอดีตามจำนวนขั้นในโซ่ ยิ่งเครือข่ายลึกเท่าไหร่ จำนวนตัวคูณยิ่งเยอะตาม (นี่คือรากของปัญหา vanishing/exploding gradient ที่ Lesson 5 จะพูดถึง).

3. ตัวอย่างคำนวณเต็มรูปแบบ: 2 Layer, 2 Training Examples

นี่คือตัวอย่างที่สไลด์เว้นตัวเลขไว้ทั้งหมด (6 หน้าต่อเนื่อง) — โครงข่ายมี input x₁,x₂ (บวก bias x₀=1) → hidden layer 2 node (a₁⁽¹⁾,a₂⁽¹⁾) → output 1 node สมมติ sigmoid ทุก node, y=1 ทั้งสอง training example.

อ่าน weight จาก diagram ตรงๆ: θ⁽¹⁾ = [[1,1,0],[1,0,1]] (แถวคือ node a₁⁽¹⁾: bias=1,x₁=1,x₂=0 และ a₂⁽¹⁾: bias=1,x₁=0,x₂=1) และ θ⁽²⁾ = [0,1,0] (output: bias=0, จาก a₁⁽¹⁾=1, จาก a₂⁽¹⁾=0).

Forward สำหรับตัวอย่างที่ 1 (x₁=1,x₂=1):

  • z₁⁽¹⁾ = 1(1)+1(1)+0(1) = 2 → a₁⁽¹⁾ = σ(2) ≈ 0.881
  • z₂⁽¹⁾ = 1(1)+0(1)+1(1) = 2 → a₂⁽¹⁾ = σ(2) ≈ 0.881
  • z₁⁽²⁾ = 0(1)+1(0.881)+0(0.881) = 0.881 → h(x) = σ(0.881) ≈ 0.707

Forward สำหรับตัวอย่างที่ 2 (x₁=1,x₂=2, weight เดิมทุกตัว):

  • z₁⁽¹⁾ = 1(1)+1(1)+0(2) = 2 → a₁⁽¹⁾ = σ(2) ≈ 0.881 (เหมือนตัวอย่างที่ 1 เป๊ะ เพราะ θ ของ x₂→a₁⁽¹⁾ เท่ากับ 0 อยู่แล้ว ไม่ว่า x₂ จะเป็น 1 หรือ 2 ก็ไม่มีผลกับ a₁⁽¹⁾)
  • z₂⁽¹⁾ = 1(1)+0(1)+1(2) = 3 → a₂⁽¹⁾ = σ(3) ≈ 0.953 (ต่างจากตัวอย่างที่ 1 เพราะ x₂ คูณกับ weight 1 ที่นี่)
  • z₁⁽²⁾ = 0(1)+1(0.881)+0(0.953) = 0.881 → h(x) = σ(0.881) ≈ 0.707

ข้อสังเกตสำคัญ: h(x) ออกมาเท่ากันทุกตัวอักษรทั้งสองตัวอย่าง (0.707) ทั้งที่ x₂ เปลี่ยนจาก 1 เป็น 2! เพราะ output ใช้ weight จาก a₂⁽¹⁾ เท่ากับ 0 (ไม่ได้ใช้ a₂⁽¹⁾ เลยในการคำนวณ h(x)) — นี่คือตัวอย่างที่จับต้องได้ว่า "weight เท่ากับ 0" หมายถึง connection นั้นไม่ส่งข้อมูลต่อไปข้างหน้าเลย.

Backward สำหรับตัวอย่างที่ 1: δ₁⁽²⁾ = h(x)−y = 0.707−1 = −0.293 ไล่ย้อนไปที่ hidden layer ด้วยสูตร δⱼ⁽¹⁾ = θⱼ₁⁽²⁾·δ₁⁽²⁾·g'(zⱼ⁽¹⁾):

  • δ₁⁽¹⁾ = θ₁₁⁽²⁾·δ₁⁽²⁾·a₁⁽¹⁾(1−a₁⁽¹⁾) = 1×(−0.293)×0.881×(1−0.881) = 1×(−0.293)×0.105 ≈ −0.0308
  • δ₂⁽¹⁾ = θ₂₁⁽²⁾·δ₁⁽²⁾·a₂⁽¹⁾(1−a₂⁽¹⁾) = 0×(−0.293)×(…) = 0

δ₂⁽¹⁾ เป็น 0 เป๊ะเพราะ weight θ₂₁⁽²⁾ (จาก a₂⁽¹⁾ ไปยัง output) เท่ากับ 0 พอดี ตอกย้ำหลักการเดียวกับ forward: ถ้า weight ไปข้างหน้าเป็น 0 gradient ที่ไหลย้อนกลับผ่านเส้นนั้นก็เป็น 0 ด้วย (node นี้ "ไม่ได้เรียนรู้อะไร" จาก output ในรอบนี้).

Backward สำหรับตัวอย่างที่ 2: คำนวณเหมือนกันทุกขั้นเพราะ h(x) และ y เท่ากันทั้งคู่ (h(x)=0.707,y=1): δ₁⁽²⁾ = 0.707−1 = −0.293, δ₁⁽¹⁾ = 1×(−0.293)×0.881×0.119 ≈ −0.0308, δ₂⁽¹⁾ = 0 เหมือนเดิม.

รวม gradient จาก 2 ตัวอย่าง (Δᵢⱼ⁽ˡ⁾ = Σ aⱼ⁽ˡ⁻¹⁾·δᵢ⁽ˡ⁾): เพราะทั้งสองตัวอย่างให้ δ เท่ากันเป๊ะ (δ₁⁽¹⁾≈−0.0308 ทั้งคู่, δ₁⁽²⁾=−0.293 ทั้งคู่) ผลรวม Δ จึงเท่ากับ 2 เท่าของตัวอย่างเดียว แล้วหารด้วย m=2 กลับมาเท่าค่าเดิม:

  • D₁₁⁽¹⁾ = (1/2)(a₁⁽⁰⁾δ₁⁽¹⁾ + a₁⁽⁰⁾δ₁⁽¹⁾) = x₁·δ₁⁽¹⁾ = 1×(−0.0308) = −0.0308 (เทียบกับ x₁=1 ในทั้งสองตัวอย่าง)
  • D₁₀⁽²⁾ = a₁⁽¹⁾·δ₁⁽²⁾ ≈ 0.881×(−0.293) ≈ −0.258

อัปเดตค่า θ₁₁⁽²⁾ ด้วย α=0.1: θ₁₁⁽²⁾ := 1 − 0.1×(−0.258) = 1 + 0.0258 = 1.0258.

สังเกตว่า θ เพิ่มขึ้นเล็กน้อย (ไม่ใช่ลดลง) เพราะ gradient เป็นค่าลบ (h(x)<y ทำนายต่ำกว่าจริง โมเดลจึงต้อง "เพิ่ม" weight ที่ส่งผลบวกต่อ output เพื่อให้ h(x) ขยับเข้าใกล้ y=1 มากขึ้นในรอบถัดไป) ส่วน θ₂₁⁽²⁾ (weight ที่เป็น 0) จะไม่เปลี่ยนแปลงเลยในรอบนี้ เพราะ gradient ของมันเป็น 0 พอดี.

4. Backpropagation Algorithm: สรุปเป็น Pseudocode ที่ใช้ได้ทุกโครงข่าย

สรุปเป็นขั้นตอนที่ใช้ได้กับโครงข่ายกี่ layer ก็ได้ (ไม่จำกัดที่ 2 layer แบบตัวอย่างข้างบน):

  1. ตั้ง Δᵢⱼ⁽ˡ⁾:=0 ทุกเส้นก่อนเริ่ม
  2. วนทุก training example: forward คำนวณ a⁽⁰⁾ ถึง a⁽ᴸ⁾ ให้ครบ
  3. คำนวณ error ที่ output δ⁽ᴸ⁾ = a⁽ᴸ⁾−y
  4. ไล่ย้อนจาก δ⁽ᴸ⁾ ไปหา δ⁽ᴸ⁻¹⁾,…,δ⁽¹⁾ ด้วย δ⁽ˡ⁻¹⁾ = (θ⁽ˡ⁾)ᵗδ⁽ˡ⁾ * g'(z⁽ˡ⁻¹⁾)
  5. สะสม Δᵢⱼ⁽ˡ⁾ += aⱼ⁽ˡ⁻¹⁾δᵢ⁽ˡ⁾ ทุกตัวอย่าง
  6. หลังวนครบทุกตัวอย่าง หาค่าเฉลี่ย Dᵢⱼ⁽ˡ⁾ = (1/m)Δᵢⱼ⁽ˡ⁾ แล้วใช้ D นี้แทน ∂J/∂θᵢⱼ⁽ˡ⁾ ใน gradient descent

สังเกตว่าตัวอย่างคำนวณมือในหัวข้อ 3 คือการรัน algorithm นี้ตรงๆแค่ 1 รอบด้วย m=2.

กลไกที่ต้องอธิบายได้
ทำไมต้องมี
ต้องสะสม (accumulate) Δ ก่อนหารด้วย m ทีหลัง แทนอัปเดต θ ทันทีหลังแต่ละ example เพราะ gradient ของ cost function ที่รวมทุก example (batch gradient descent) คือค่าเฉลี่ยของ gradient แต่ละ example — อัปเดตทันทีทุก example คือ SGD (Lesson 4) ซึ่งเป็นอัลกอริทึมคนละตัว
เปลี่ยนแล้วเกิดอะไร
ถ้า m=4 และ 4 example ให้ δ ต่างกัน [−0.03,−0.02,−0.05,0.01] ค่า D จะเป็นค่าเฉลี่ย=(−0.03−0.02−0.05+0.01)/4=−0.0225 ไม่ใช่ผลรวมตรงๆ (−0.09) เพราะสูตร D=(1/m)Δ หารด้วย m เสมอ — ยิ่ง m มาก แต่ละ example ยิ่งมีน้ำหนักต่อการอัปเดตน้อยลงตามสัดส่วน
เชื่อมกับ
การหารด้วย m นี้คือกลไกเดียวกับ "mean" ใน MSE/cross-entropy cost function ตั้งแต่ Lesson 1 — cost function ทุกตัวในวิชานี้คือค่าเฉลี่ย ไม่ใช่ผลรวมดิบ

5. Activation Function และอนุพันธ์: ตัวเลือกที่ส่งผลต่อ Gradient

สไลด์พิสูจน์เต็มด้วย quotient rule: σ'(z) = [(1+e⁻ᶻ)·0 − 1·(−e⁻ᶻ)] / (1+e⁻ᶻ)² = e⁻ᶻ/(1+e⁻ᶻ)² แล้วแยก e⁻ᶻ/(1+e⁻ᶻ)² = σ(z)·[e⁻ᶻ/(1+e⁻ᶻ)] = σ(z)·[(1+e⁻ᶻ)/(1+e⁻ᶻ) − 1/(1+e⁻ᶻ)] = σ(z)·(1−σ(z)).

ผลลัพธ์สุดท้ายที่ต้องจำ: σ'(z) = σ(z)(1−σ(z)) ดูกราฟด้านขวา: อนุพันธ์ (เส้นสีแดง) มีค่าสูงสุดแค่ 0.25 ที่ z=0 และเข้าใกล้ 0 อย่างรวดเร็วเมื่อ z ห่างจาก 0 ไปทางบวกหรือลบมาก.

นี่คือรากของปัญหา vanishing gradient ที่ Lesson 5 จะขยายผล: ยิ่ง sigmoid หลาย layer ต่อกัน ยิ่งคูณเลขที่ ≤0.25 ซ้ำหลายรอบ ค่า gradient จึงเล็กลงเรื่อยๆแบบทวีคูณ.

ReLU เรียบง่ายกว่ามาก: f(x)=max(0,x) อนุพันธ์เป็น 0 หรือ 1 เท่านั้น (ไม่มีค่าระหว่างกลางที่ลดขนาดลงเรื่อยๆแบบ sigmoid) เมื่อ x≥0 อนุพันธ์คงที่ที่ 1 พอดี ไม่ทำให้ gradient หดตัวเลยไม่ว่าจะผ่านกี่ layer — นี่คือเหตุผลหลักที่ ReLU เป็นตัวเลือกอันดับหนึ่งของ hidden layer ในเครือข่ายลึก.

แต่ก็มีข้อเสีย: เมื่อ x<0 อนุพันธ์เป็น 0 เป๊ะ (node "ตาย" ไม่เรียนรู้อะไรต่ออีกถ้าเข้าโซนนี้ถาวร) เป็นที่มาของ Leaky ReLU ที่ให้ความชันเล็กน้อย (0.01) แทน 0 ไปเลยในโซน x<0.

กลไกที่ต้องอธิบายได้
ทำไมต้องมี
"รูปร่าง" ของอนุพันธ์ (ไม่ใช่แค่ output range) กำหนดว่า gradient จะไหลย้อนกลับได้ไกลแค่ไหน เพราะอนุพันธ์คือตัวคูณในสูตร δ โดยตรง (g' ในหัวข้อ 2) — ฟังก์ชันที่ output range ดูดี (sigmoid บีบ [0,1]) แต่อนุพันธ์เล็ก/ไม่สม่ำเสมอ ยังทำให้เทรนยากได้
เปลี่ยนแล้วเกิดอะไร
ที่ z=2 (ไม่ใช่ z=0) sigmoid derivative เท่ากับเท่าไหร่? σ(2)=1/(1+e⁻²)≈0.881, σ'(2)=0.881×(1−0.881)=0.881×0.119≈0.105 — ลดลงมากกว่าครึ่งจากค่าสูงสุด 0.25 ทั้งที่ z=2 ไม่ได้ไกลจาก 0 มากเลย แสดงว่า sigmoid เริ่ม saturate เร็วมาก
เชื่อมกับ
z=2 นี้คือค่า z₁⁽¹⁾ เดียวกับในตัวอย่างคำนวณเต็มรูปแบบของหัวข้อ 3 พอดี — δ₁⁽¹⁾ ในตัวอย่างนั้นเล็ก (≈−0.0308) ส่วนหนึ่งเพราะ g'(2)≈0.105 ไม่ใช่ 0.25 (ตัวคูณที่หายไปเกินครึ่งตั้งแต่ layer เดียว)
คำถาม 5Activation Derivative
อนุพันธ์ของ sigmoid function σ'(z)=σ(z)(1−σ(z)) มีค่าสูงสุดเท่ากับเท่าไหร่ และเกิดขึ้นที่ z เท่าไหร่?

ทำไม activation function ต้อง non-linear? สไลด์พิสูจน์ด้วยการลองแทน f(x)=x (linear) ทุก node:

ถ้า f(x)=x ทุก node: z₁⁽¹⁾ = θ₁₀⁽¹⁾+θ₁₁⁽¹⁾x₁+θ₁₂⁽¹⁾x₂ แล้ว a₁⁽¹⁾ = f(z₁⁽¹⁾) = z₁⁽¹⁾ (ไม่เปลี่ยนอะไรเลย).

พอไป layer 2: z₁⁽²⁾ = θ₁₀⁽²⁾+θ₁₁⁽²⁾a₁⁽¹⁾+… แทนค่า a⁽¹⁾ ที่เป็น linear combination ของ x เข้าไป จะลดรูปกลับมาเป็น z₁⁽²⁾ = a+bx₁+cx₂ (linear function ของ x₁,x₂ ตัวเดียว ไม่ว่าจะมีกี่ layer ก็ตาม).

นี่คือเหตุผลที่ต้องมี non-linear activation: ถ้าไม่มี การต่อหลาย layer จะไม่ต่างอะไรกับ layer เดียว (linear regression ธรรมดา) เพราะ "linear ซ้อน linear ยังคงเป็น linear เสมอ".

กลไกที่ต้องอธิบายได้
ทำไมต้องมี
การพิสูจน์นี้แสดงว่า "ความลึก" เพิ่ม representational power ได้ก็ต่อเมื่อมี non-linearity คั่นเท่านั้น — ถ้าไม่มี ต่อกี่ layer สูตรก็ยุบรวมเป็น linear function เดียวเสมอ (พิสูจน์ด้วยพีชคณิตล้วนๆ ไม่ใช่แค่ observation เชิงประสบการณ์)
เปลี่ยนแล้วเกิดอะไร
ถ้าใช้ linear activation ในเครือข่าย 3 layer (ไม่ใช่ 2) จะยุบเหลือ linear function เหมือนกันไหม? ใช่ — layer 3 คือ z⁽³⁾=θ⁽³⁾·a⁽²⁾ แทน a⁽²⁾ ที่เป็น linear ของ a⁽¹⁾ ซึ่งเป็น linear ของ x อีกที จะได้ z⁽³⁾ เป็น linear combination ของ x ชั้นเดียวเสมอ ไม่ว่าจะมีกี่ layer (สมบัติ transitive ของ linear composition)
เชื่อมกับ
เหตุผลเดียวกับที่ Lesson 2 หัวข้อ 1 บอกว่า NN แก้ปัญหา "ต้องแจกแจง polynomial feature มือ" ได้ — ถ้าไม่มี non-linearity ที่ hidden layer เครือข่ายก็ทำได้แค่สิ่งที่ linear regression ทำได้อยู่แล้ว ไม่ต่างอะไรเลย

6. Output Layer และ Softmax: ต่อจาก Lesson 1

สูตร Softmax เหมือนที่คำนวณตัวอย่างจริงไปแล้วใน Lesson 1 หัวข้อ 8: aᵢ⁽ᴸ⁾ = eᶻⁱ⁽ᴸ⁾ / Σₙ eᶻⁿ⁽ᴸ⁾.

สิ่งใหม่ที่นี่คือ Softmax ถูกมองเป็น "activation function ของทั้ง output layer พร้อมกัน" ไม่ใช่ทีละ node เหมือน sigmoid/ReLU (Softmax ต้องรู้ค่า z ของทุก output node พร้อมกันก่อนจะ normalize ได้ ในขณะที่ sigmoid คำนวณแยกแต่ละ node ได้อิสระ).

เมื่อใช้ Softmax ที่ output ร่วมกับ Cross-Entropy Loss การพิสูจน์ δ⁽ᴸ⁾ = a⁽ᴸ⁾−y ในหัวข้อ 2-3 ยังใช้ได้เหมือนเดิมทุกตัวอักษร (เป็นคุณสมบัติพิเศษที่ Softmax+Cross-Entropy ลดรูปสวยเหมือน Sigmoid+Cross-Entropy).

กลไกที่ต้องอธิบายได้
ทำไมต้องมี
ทำไม softmax ต้อง normalize ทั้ง layer พร้อมกัน ไม่แยกทีละ node แบบ sigmoid — เพราะเป้าหมายคือ "ความน่าจะเป็นของแต่ละ class ที่รวมกันได้ 1 พอดี" (mutually exclusive) ถ้าคำนวณแยก node ไม่มีทางบังคับผลรวม=1 ได้ ต้องรู้ z ของทุก node พร้อมกันก่อนหารด้วยผลรวม
เปลี่ยนแล้วเกิดอะไร
ถ้า logit เปลี่ยนจาก z=[2,1,0] เป็น z=[12,11,10] (บวก 10 ทุกตัว) probability เปลี่ยนไหม? e¹²/(e¹²+e¹¹+e¹⁰) = e¹⁰(e²)/[e¹⁰(e²+e+1)] = e²/(e²+e+1) เท่ากับตัวอย่างเดิมเป๊ะ (≈0.665) เพราะ e^(z+c)=e^z·e^c ตัว e^c หักล้างกันได้ทั้งเศษส่วน — softmax invariant ต่อการบวกค่าคงที่ให้ z ทุกตัว
เชื่อมกับ
คุณสมบัตินี้คือเหตุผลที่ implementation จริง (Keras/PyTorch) มักลบ max(z) ออกจาก z ก่อนคำนวณ softmax (numerical stability) โดยไม่เปลี่ยนผลลัพธ์เลย — เชื่อมกับการเขียนโค้ด Keras จริงใน Lesson 5

8. Binary Classification Exercise: ฝึกเขียนสูตรทั่วไปซ้ำ

สไลด์ทิ้งแบบฝึกหัดไว้ 2 หน้า (forward + backward) โดยใช้ shallow neural network เดิม (input 2 node, hidden 10 node, output 1 node) แต่ไม่ให้ค่า θ จริง — เป้าหมายคือฝึกเขียนสูตรทั่วไปซ้ำด้วยตัวเอง:

  • Forward: zⱼ⁽¹⁾ = θⱼ₀⁽¹⁾+θⱼ₁⁽¹⁾x₁+θⱼ₂⁽¹⁾x₂ สำหรับ j=1..10, aⱼ⁽¹⁾=g(zⱼ⁽¹⁾), แล้ว z₁⁽²⁾ = θ₁₀⁽²⁾+Σⱼθ₁ⱼ⁽²⁾aⱼ⁽¹⁾ (ผลรวมนี้ยาวกว่าตัวอย่างก่อนหน้าเพราะมี hidden node 10 ตัวไม่ใช่ 2-3 ตัว)
  • Backward: δ₁⁽²⁾=h(x)−y แล้ว δⱼ⁽¹⁾ = θ₁ⱼ⁽²⁾·δ₁⁽²⁾·g'(zⱼ⁽¹⁾) สำหรับ j=1..10

โครงสร้างสูตรเหมือนตัวอย่างหัวข้อ 3 ทุกตัวอักษร ต่างกันแค่ "จำนวน node" ที่มากขึ้น พิสูจน์ว่าสูตร backprop สเกลไปกับขนาดเครือข่ายได้โดยไม่ต้องเปลี่ยนกลไกอะไรเลย.

กลไกที่ต้องอธิบายได้
ทำไมต้องมี
สูตรทั่วไป (10 hidden node) มีรูปร่างเดียวกับตัวอย่าง 2-3 node เป๊ะ ไม่มีเทอมพิเศษเพิ่ม เพราะ backprop เป็น local operation — แต่ละ node คำนวณ δ ของตัวเองจากแค่ δ ของ node ที่มันเชื่อมต่อโดยตรงใน layer ถัดไป ไม่ต้องรู้ว่าเครือข่ายมี node ทั้งหมดกี่ตัว
เปลี่ยนแล้วเกิดอะไร

เชื่อมกับ
คุณสมบัติ "local computation ไม่ขึ้นกับขนาดเครือข่าย" นี้คือเหตุผลที่ backprop สเกลไปเทรนเครือข่ายที่มีพารามิเตอร์เป็นพันล้านตัวได้จริง (LLM ใน timeline ของ Lesson 1) — ถ้าต้องมีสูตรพิเศษต่อขนาดเครือข่าย จะ implement เป็นโค้ดทั่วไปไม่ได้เลย

ในขั้นตอน Backpropagation Algorithm สูตร δ⁽ˡ⁻¹⁾ = (θ⁽ˡ⁾)ᵗδ⁽ˡ⁾ * g'(z⁽ˡ⁻¹⁾) ใช้คำนวณอะไร และทำไมต้องมีเทอม g'(z⁽ˡ⁻¹⁾) คูณอยู่ด้วย?
คำถาม 9Gradient Descent Update
จากตัวอย่างคำนวณเต็มรูปแบบ เมื่อ gradient D₁₀⁽²⁾ ≈ −0.258 และ α=0.1 ค่า θ₁₀⁽²⁾ เดิม (=0) จะถูกอัปเดตเป็นเท่าไหร่?
คำถาม 10Why Non-linear
ถ้าทุก node ในเครือข่ายใช้ activation function แบบ linear (f(x)=x) ไม่ว่าจะมีกี่ layer ผลลัพธ์สุดท้ายของเครือข่ายจะเป็นอย่างไร?

ชัยชนะของบทเรียนนี้
คุณควรพิสูจน์สูตร δ⁽ᴸ⁾=a⁽ᴸ⁾−y และ δ⁽ˡ⁻¹⁾=(θ⁽ˡ⁾)ᵗδ⁽ˡ⁾*g'(z⁽ˡ⁻¹⁾) ได้ด้วย chain rule เอง, รันตัวอย่างคำนวณเต็ม 2 layer 2 examples ได้มือ (forward→δ→Δ→D→update θ), อธิบายอนุพันธ์ sigmoid/ReLU และผลต่อ gradient ได้, และอธิบายได้ว่าทำไมต้องมี non-linear activation — นี่คือสูตรเดียวที่ Lesson 4 จะขยายจาก 2 layer เป็น L layer โดยไม่มีอะไรเปลี่ยนนอกจากจำนวนรอบ.
