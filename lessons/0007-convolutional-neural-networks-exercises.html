ข้อ 17shape และ parameter ทั้ง network
ภาพ 32×32×3 → Conv2D(16, 3, padding="same") → MaxPooling2D(2) → Conv2D(32, 3) → MaxPooling2D(2) → Flatten → Dense(10) เขียน output shape และจำนวน parameter ทุกชั้นพร้อมผลรวม

Conv1 same: 32×32×16, (3·3·3 + 1)·16 = 448 · Pool: 16×16×16, 0

Conv2 valid: 16 − 3 + 1 = 14 จึง 14×14×32, (3·3·16 + 1)·32 = 4,640 · Pool: 7×7×32, 0

Flatten: 7·7·32 = 1,568 · Dense(10): 1,568·10 + 10 = 15,690 · รวม 448 + 4,640 + 15,690 = 20,778

ข้อ 18pooling กับ parameter
อธิบายว่าทำไม pooling layer มี parameter 0 แต่กลับช่วยลดจำนวน parameter ของโมเดล ยกตัวอย่างตัวเลขจากตาราง parameters summary

pooling แค่เลือกค่าสูงสุดหรือเฉลี่ยในหน้าต่าง ไม่มี weight ให้เรียน จึงมี parameter 0 (pool size และ stride เป็น hyperparameter)

แต่มันลดกว้างและสูงของ feature map ทำให้ vector หลัง flatten สั้นลง dense layer แรกจึงมี weight น้อยลง: ไม่มี pooling flatten ได้ 3,380 → 338,100 parameter · มี pooling flatten ได้ 180 → 18,100 ลดลงราว 18.7 เท่า

ข้อ 19channel ของ filter
ทำไม filter ที่ใช้กับภาพ RGB ต้องมีขนาด f×f×3 และทำไม output ของ filter หนึ่งตัวจึงมีแค่ 1 channel

หนึ่งตำแหน่งต้องคูณกับทุก channel ของ input filter จึงต้องมีชั้นละหนึ่ง channel เท่ากับ input (n_C = 3)

ผลคูณของทุกช่องทุก channel ถูกบวกรวมเป็นตัวเลขเดียวต่อตำแหน่ง filter หนึ่งตัวจึงให้ feature map แผ่นเดียว ถ้าต้องการ output หลาย channel ต้องใช้หลาย filter (channel ของ output = จำนวน filter)
