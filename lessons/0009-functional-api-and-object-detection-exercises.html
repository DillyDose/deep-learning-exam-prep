ข้อ 20เขียนโมเดลสองหัวด้วย Functional API
input 20 feature → Dense(64, relu) → แตกสองหัว: หัว class 5 class และหัว regression 1 ค่า เขียนโค้ด Keras compile ให้ classification มีน้ำหนัก 0.7 และนับ parameter ทั้งหมด

inp = Input(shape=(20,)) · h = Dense(64, activation="relu")(inp) · cls = Dense(5, activation="softmax")(h) · reg = Dense(1)(h) · model = Model(inputs=inp, outputs=[cls, reg])

model.compile(loss=["sparse_categorical_crossentropy", "mse"], loss_weights=[0.7, 0.3], optimizer="adam")

parameter: 20·64 + 64 = 1,344 · 64·5 + 5 = 325 · 64 + 1 = 65 · รวม 1,734

ข้อ 21NMS ทีละขั้น
กรอบของ class dog สี่กรอบ: A 0.95, B 0.85, C 0.60, D 0.40 IoU(A,B) = 0.7, IoU(A,C) = 0.1, IoU(B,C) = 0.2 confidence threshold 0.5 NMS threshold 0.5 เหลือกรอบใด อธิบายทีละขั้น

ขั้น 1 ทิ้ง D เพราะ 0.40 ต่ำกว่า 0.5 เหลือ A, B, C

ขั้น 2 เลือก A คะแนนสูงสุด ตรวจ IoU กับที่เหลือ: B 0.7 เกิน 0.5 ถูก suppress · C 0.1 ไม่ถูก suppress

ขั้น 3 เลือก C ซึ่งสูงสุดที่เหลือ ไม่มีกรอบเหลือให้ตรวจ · ผลคือ A กับ C คือสุนัขสองตัว

ข้อ 22ขนาด output ของ YOLO
detector แบบ YOLO ใช้ภาพ 320×320 ตรวจที่ stride 32 และ 16 ใช้ 2 anchor ต่อ cell และมี 20 class เขียน shape output ของแต่ละ scale และจำนวนกรอบทั้งหมด

ต่อกรอบ 5 + 20 = 25 · ต่อ cell 2 × 25 = 50 channel

stride 32: 320/32 = 10 ได้ (10, 10, 50) · stride 16: 320/16 = 20 ได้ (20, 20, 50)

กรอบ: (100 + 400) × 2 = 1,000 กรอบ ก่อนผ่าน NMS
