Backpropagation: คำนวณ Gradient ย้อนกลับด้วย Chain Rule

นี่คือหัวใจของข้อสอบวิชานี้. สไลด์ของบทนี้ตั้งใจเว้น "คำตอบตัวเลข" ของตัวอย่างไว้ให้กรอกในคาบ — บทเรียนนี้จะคำนวณให้ครบทุกตัวเลข พร้อมพิสูจน์ที่มาของสูตร \(\delta\) ทีละขั้น.

ภาพรวมก่อนลงรายละเอียด — Backprop คือการตอบคำถามเดียว

หลังทำ forward ได้ค่าทำนาย \(h(x)\) เทียบกับคำตอบจริง \(y\) แล้ว เราต้องรู้ว่า weight แต่ละตัวควรขยับไปทางไหนและมากแค่ไหน เพื่อให้ cost ลดลง. นั่นคือค่า \(\partial J/\partial\theta\) ของทุก \(\theta\) ในโครงข่าย. Backprop คือวิธีคำนวณอนุพันธ์ทั้งหมดนี้อย่างประหยัด โดยเริ่มจาก error ที่ output แล้วส่ง "ส่วนแบ่งความผิด" (\(\delta\)) ย้อนกลับทีละ layer.

ลำดับงานเสมอ: ① forward (ได้ \(z, a\) ทุก layer) → ② \(\delta\) ที่ output → ③ ส่ง \(\delta\) ย้อนกลับทีละ layer → ④ \(\partial J/\partial\theta = \delta\times a\) → ⑤ อัปเดต \(\theta\).

1. Chain Rule: เครื่องมือเดียวที่ใช้พิสูจน์ backprop ทั้งหมด

อนุพันธ์คืออะไร (ภาษาคน): \(\dfrac{dy}{dx}\) = "ถ้า \(x\) เปลี่ยนไปนิดเดียว \(y\) จะเปลี่ยนไปกี่เท่าของนิดนั้น". Chain rule ใช้เมื่อ \(y\) ขึ้นกับ \(x\) ผ่านตัวกลาง: ถ้า \(y=f(u)\) และ \(u=g(x)\) แล้ว

$$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$$

เหมือนอัตราแลกเงิน: บาท→ดอลลาร์ ×0.03 แล้ว ดอลลาร์→ยูโร ×0.92 ⇒ บาท→ยูโร ×(0.03×0.92) — อัตราแต่ละทอด "คูณต่อกัน"

สไลด์ทิ้งโจทย์ฝึกมือไว้ 2 ข้อก่อนเข้า backprop จริง:

โจทย์ 1: หา \(\dfrac{dy}{dx}\) เมื่อ \(y = e^{x^3}\)
  1. แยกเป็นสองทอด
    $$u = x^3,\qquad y = e^{u}$$
  2. หาอนุพันธ์แต่ละทอด
    $$\frac{dy}{du} = e^{u} = e^{x^3},\qquad \frac{du}{dx} = 3x^2$$
  3. คูณต่อกัน
    $$\frac{dy}{dx} = e^{x^3}\cdot 3x^2$$

แพทเทิร์น: "คงฟังก์ชันชั้นนอกไว้ทั้งดุ้น (\(e^{x^3}\)) แล้วคูณอนุพันธ์ของชั้นใน (\(3x^2\))" — กลไกเดียวกับที่ใช้แยก \(\partial J/\partial\theta\) ทีละชั้นในโครงข่าย.

โจทย์ 2: หา \(\dfrac{dy}{dx}\) เมื่อ \(y = (2x-5)^{10}\) (hint ในสไลด์: ให้ \(u=2x-5\))
  1. แยกทอด (computation graph: \(x \to u \to y\))
    $$u = 2x-5,\qquad y = u^{10}$$
  2. อนุพันธ์แต่ละทอด
    $$\frac{dy}{du} = 10u^{9},\qquad \frac{du}{dx} = 2$$
  3. คูณ แล้วแทน \(u\) กลับ
    $$\frac{dy}{dx} = 10u^{9}\cdot 2 = 20\,(2x-5)^{9}$$
  4. ตรวจด้วยตัวเลข ที่ \(x=3\) (\(u=1\))
    $$\frac{dy}{dx}\Big|_{x=3} = 20(1)^9 = 20$$

    ลองขยับ \(x\) จาก 3 เป็น 3.001: \(u=1.002\) ⇒ \(y = 1.002^{10} = 1.0202\) ⇒ \(\Delta y/\Delta x = 0.0202/0.001 \approx 20.2\) ✓ (ใกล้ 20)

โครงข่ายประสาทเทียมคือ computation graph ที่ยาวกว่านี้ (\(z^{[1]}\to a^{[1]}\to z^{[2]}\to a^{[2]}\to J\)) แค่นั้นเอง.

2. จาก Chain Rule สู่ \(\partial J/\partial\theta\): สูตรทั่วไปของ Backprop

โครงข่าย 2 layer คือ \(h(x) = g\big(\theta^{[2]}\,g(\theta^{[1]}x)\big)\). ที่สนใจคือค่า cost ต่อ 1 ตัวอย่าง (sigmoid ที่ output + cross-entropy จาก Lesson 1):

$$J = -\left[y\ln a^{[2]} + (1-y)\ln\!\left(1-a^{[2]}\right)\right]$$

2.1 ทำไมต้อง forward ก่อน

ก่อนย้อนกลับต้องมีค่า \(z, a\) ทุก layer จากการ forward (Lesson 2 §8):

$$z_1^{[2]} = \theta_{10}^{[2]} + \theta_{11}^{[2]}a_1^{[1]} + \theta_{12}^{[2]}a_2^{[1]} + \theta_{13}^{[2]}a_3^{[1]},\qquad h_\theta(x) = a_1^{[2]} = g\!\left(z_1^{[2]}\right)$$

2.2 นิยาม \(\delta\) และสูตรสำเร็จของสไลด์

สไลด์นิยาม \(\delta_j^{[l]} = \dfrac{\partial J}{\partial z_j^{[l]}}\) = "error" ที่ node \(j\) ใน layer \(l\) — วัดว่า \(J\) จะเปลี่ยนเท่าไรถ้า \(z\) ตัวนี้เปลี่ยน. และให้สูตร 2 บรรทัด:

$$\delta_1^{[2]} = h(x) - y,\qquad \delta_j^{[1]} = \theta_{1j}^{[2]}\,\delta_1^{[2]}\,g'\!\left(z_j^{[1]}\right)$$

output: error = ทำนาย − จริง. hidden: node นี้ "ยืม" error ของ layer ถัดไป × weight ที่เชื่อม × ความชันของ activation ของ node นี้เอง

2.3 พิสูจน์สูตรทีละขั้น

พิสูจน์ ①: \(\delta^{[2]} = \partial J/\partial z^{[2]} = a^{[2]} - y\)
เขียน \(a\) แทน \(a^{[2]}\) เพื่อความสั้น; \(a = g(z^{[2]}) = \dfrac{1}{1+e^{-z^{[2]}}}\)
  1. อนุพันธ์ของ \(J\) เทียบ \(a\)
    $$\frac{\partial J}{\partial a} = -\frac{y}{a} + \frac{1-y}{1-a} = \frac{-y(1-a) + (1-y)a}{a(1-a)} = \frac{a-y}{a(1-a)}$$
  2. อนุพันธ์ของ sigmoid (พิสูจน์ใน §5): \(\dfrac{\partial a}{\partial z^{[2]}} = a(1-a)\)
  3. คูณตาม chain rule — ตัว \(a(1-a)\) หักล้างกันพอดี
    $$\frac{\partial J}{\partial z^{[2]}} = \frac{a-y}{a(1-a)}\cdot a(1-a) = a - y$$
$$\delta^{[2]} = a^{[2]} - y = h(x) - y$$
พิสูจน์ ②: gradient ของ \(\theta^{[2]}\) (layer สุดท้าย — โซ่ 1 ขั้น)
  1. เขียน chain rule
    $$\frac{\partial J}{\partial\theta_{1j}^{[2]}} = \frac{\partial J}{\partial z^{[2]}}\cdot\frac{\partial z^{[2]}}{\partial\theta_{1j}^{[2]}}$$
  2. เทอมที่สอง: \(z^{[2]} = \theta_{10}^{[2]}+\sum_j\theta_{1j}^{[2]}a_j^{[1]}\) ⇒ อนุพันธ์เทียบ \(\theta_{1j}^{[2]}\) เหลือ \(a_j^{[1]}\) (และ \(a_0^{[1]}=1\) สำหรับ bias)
    $$\frac{\partial z^{[2]}}{\partial\theta_{1j}^{[2]}} = a_j^{[1]}$$
$$\frac{\partial J}{\partial\theta_{1j}^{[2]}} = \delta^{[2]}\cdot a_j^{[1]} = (h(x)-y)\,a_j^{[1]}$$
พิสูจน์ ③: gradient ของ \(\theta^{[1]}\) (layer แรก — โซ่ 4 ทอด)
  1. เขียนโซ่: \(\theta^{[1]}_{ji}\to z_j^{[1]}\to a_j^{[1]}\to z^{[2]}\to J\)
    $$\frac{\partial J}{\partial\theta_{ji}^{[1]}} = \underbrace{\frac{\partial J}{\partial z^{[2]}}}_{\delta^{[2]}}\cdot\underbrace{\frac{\partial z^{[2]}}{\partial a_j^{[1]}}}_{\theta_{1j}^{[2]}}\cdot\underbrace{\frac{\partial a_j^{[1]}}{\partial z_j^{[1]}}}_{g'(z_j^{[1]})}\cdot\underbrace{\frac{\partial z_j^{[1]}}{\partial\theta_{ji}^{[1]}}}_{x_i}$$
  2. แทนทีละเทอม

    \(\delta^{[2]}\) จากพิสูจน์ ① · \(\theta_{1j}^{[2]}\) เพราะ \(z^{[2]}\) เป็นผลรวมถ่วงน้ำหนักของ \(a^{[1]}\) · \(g'(z_j^{[1]}) = a_j^{[1]}(1-a_j^{[1]})\) สำหรับ sigmoid · \(x_i\) เพราะ \(z_j^{[1]}=\sum_i\theta_{ji}^{[1]}x_i\)

  3. จับกลุ่ม 3 ตัวแรกเป็น \(\delta_j^{[1]}\)
    $$\delta_j^{[1]} \equiv \delta^{[2]}\,\theta_{1j}^{[2]}\,g'(z_j^{[1]})\quad\Rightarrow\quad \frac{\partial J}{\partial\theta_{ji}^{[1]}} = \delta_j^{[1]}\,x_i$$

ทุก layer ได้กฎเดียวกัน: $$\dfrac{\partial J}{\partial\theta_{ij}^{[l]}} = \delta_i^{[l]}\cdot a_j^{[l-1]}$$ — (error ของ node ปลายทาง) × (ค่าที่ส่งมาจากต้นทาง). สังเกตว่าสูตรเต็มมี "4 ตัวคูณ" ตามจำนวนทอดในโซ่ — เครือข่ายยิ่งลึกยิ่งมีตัวคูณ \(g'\) มาก (รากของ vanishing gradient, Lesson 5).

รูปแบบเมทริกซ์ (ที่ใช้ตอนเขียนโค้ด — ทุก node ใน layer พร้อมกัน):

$$\delta^{[l-1]} = \left(\theta^{[l]\top}\delta^{[l]}\right)\odot g'\!\left(z^{[l-1]}\right)$$

เครื่องหมาย \(\odot\) คือคูณทีละสมาชิก (element-wise) ไม่ใช่คูณเมทริกซ์. ตัวอย่างขนาด: layer 1 มี 3 node, layer 2 มี 1 node ⇒ \(\theta^{[2]}\) ขนาด \(1\times4\), \(\theta^{[2]\top}\delta^{[2]}\) ขนาด \((4\times1)(1\times1)=4\times1\) แล้วตัดแถว bias (แถวแรก) ทิ้งเหลือ \(3\times1\) คูณ \(g'(z^{[1]})\) ที่ \(3\times1\).

3. ตัวอย่างคำนวณเต็มรูปแบบ: 2 Layer, 2 Training Examples

ตัวอย่างที่สไลด์เว้นตัวเลขไว้ทั้งหมด (หลายหน้าต่อเนื่อง). โครงข่าย: input \(x_1,x_2\) (+ bias \(x_0=1\)) → hidden 2 node → output 1 node, sigmoid ทุก node, \(y=1\) ทั้งสองตัวอย่าง.

อ่าน weight จาก diagram (แถว = node ปลายทาง; คอลัมน์ = bias, \(x_1\), \(x_2\)):

$$\theta^{[1]} = \begin{bmatrix}1&1&0\\1&0&1\end{bmatrix},\qquad \theta^{[2]} = \begin{bmatrix}0&1&0\end{bmatrix}\ (\text{bias},\ a_1^{[1]},\ a_2^{[1]})$$

node 1 ของ hidden ใช้เฉพาะ \(x_1\) (weight ของ \(x_2\) = 0); node 2 ใช้เฉพาะ \(x_2\); output ใช้เฉพาะ hidden node 1

ขั้น A — Forward ตัวอย่างที่ 1: \(x=(1,1)\)
  1. hidden \(z\)
    $$z_1^{[1]} = 1(1)+1(1)+0(1) = 2,\qquad z_2^{[1]} = 1(1)+0(1)+1(1) = 2$$
  2. hidden \(a = g(z)\)
    $$a_1^{[1]} = g(2) = 0.881,\qquad a_2^{[1]} = g(2) = 0.881$$
  3. output
    $$z^{[2]} = 0(1)+1(0.881)+0(0.881) = 0.881,\qquad h(x) = g(0.881) = 0.707$$
ขั้น B — Forward ตัวอย่างที่ 2: \(x=(1,2)\) (weight เดิม)
  1. hidden
    $$z_1^{[1]} = 1+1(1)+0(2) = 2\Rightarrow a_1^{[1]} = 0.881;\qquad z_2^{[1]} = 1+0(1)+1(2) = 3\Rightarrow a_2^{[1]} = g(3) = 0.953$$
  2. output
    $$z^{[2]} = 0+1(0.881)+0(0.953) = 0.881,\qquad h(x) = 0.707$$

ข้อสังเกต: \(h(x)\) เท่ากันเป๊ะ (0.707) ทั้งที่ \(x_2\) เปลี่ยนจาก 1 เป็น 2 — เพราะ (1) \(a_1^{[1]}\) ไม่ขึ้นกับ \(x_2\) (weight = 0) และ (2) output ไม่ใช้ \(a_2^{[1]}\) (weight = 0). "weight = 0" แปลว่าเส้นนั้นไม่ส่งข้อมูลไปข้างหน้าเลย.

ขั้น C — Backward (ผลเหมือนกันทั้งสองตัวอย่าง เพราะ \(h\) และ \(y\) เท่ากัน)
  1. \(\delta\) ที่ output
    $$\delta^{[2]} = h(x)-y = 0.707 - 1 = -0.293$$
  2. \(g'\) ของ hidden node 1 (\(z_1^{[1]}=2\) ทั้งสองตัวอย่าง)
    $$g'(2) = 0.881(1-0.881) = 0.105$$
  3. \(\delta\) ของ hidden node 1 (weight ขาออก \(\theta_{11}^{[2]}=1\))
    $$\delta_1^{[1]} = \theta_{11}^{[2]}\,\delta^{[2]}\,g'(z_1^{[1]}) = 1\times(-0.293)\times0.105 = -0.0308$$
  4. \(\delta\) ของ hidden node 2 (weight ขาออก \(\theta_{12}^{[2]}=0\))
    $$\delta_2^{[1]} = 0\times(-0.293)\times g'(z_2^{[1]}) = 0$$

\(\delta_2^{[1]}=0\) เป๊ะเพราะ weight ขาออกเป็น 0: ถ้า weight ไปข้างหน้าเป็น 0 gradient ที่ไหลย้อนผ่านเส้นนั้นก็เป็น 0 — node นี้ไม่ได้เรียนรู้อะไรจาก output ในรอบนี้.

ขั้น D — สะสม gradient จาก 2 ตัวอย่าง แล้วอัปเดต (\(m=2\), \(\alpha = 0.1\))
กฎ: \(\Delta_{ij}^{[l]} = \sum_{\text{ตัวอย่าง}}\delta_i^{[l]}a_j^{[l-1]}\) แล้วเฉลี่ย \(D_{ij}^{[l]} = \dfrac{1}{m}\Delta_{ij}^{[l]}\) และอัปเดต \(\theta := \theta - \alpha D\)
  1. gradient ของ \(\theta^{[2]}\) (ค่า \(a^{[1]}\) ตัวอย่างที่ 1: 0.881, 0.881 ; ตัวอย่างที่ 2: 0.881, 0.953)
    $$\begin{aligned} D_{10}^{[2]} &= \tfrac12\big[1(-0.293)+1(-0.293)\big] = -0.293\\ D_{11}^{[2]} &= \tfrac12\big[0.881(-0.293)+0.881(-0.293)\big] = -0.258\\ D_{12}^{[2]} &= \tfrac12\big[0.881(-0.293)+0.953(-0.293)\big] = -0.269 \end{aligned}$$
  2. gradient ของ \(\theta^{[1]}\) แถว node 1 (\(\delta_1^{[1]}=-0.0308\); ตัวอย่างที่ 1: \(x=(1,1)\), ตัวอย่างที่ 2: \(x=(1,2)\))
    $$D_{10}^{[1]} = -0.0308,\quad D_{11}^{[1]} = -0.0308,\quad D_{12}^{[1]} = \tfrac12\big[1(-0.0308)+2(-0.0308)\big] = -0.0462$$

    แถว node 2: \(\delta_2^{[1]}=0\) ⇒ gradient ทั้งแถว = 0

  3. อัปเดต \(\theta := \theta - 0.1\,D\)
    $$\theta^{[2]}:\ [0,\ 1,\ 0]\ \to\ [0.0293,\ 1.0258,\ 0.0269]$$ $$\theta^{[1]}\text{ แถว 1}:\ [1,\ 1,\ 0]\ \to\ [1.0031,\ 1.0031,\ 0.0046],\qquad \text{แถว 2 ไม่เปลี่ยน }[1,0,1]$$
  4. ตรวจว่า cost ลดจริง

    forward ใหม่ได้ \(h=0.7226\) และ \(0.7231\) (จาก 0.707) ⇒ cost เฉลี่ย \(-\ln h\) ลดจาก \(0.3467\) เหลือ \(0.3245\)

4. Backpropagation Algorithm: สรุปเป็น Pseudocode ที่ใช้ได้ทุกโครงข่าย

สไลด์สรุปขั้นตอนที่ใช้ได้กับโครงข่ายกี่ layer ก็ได้ (\(L\) = จำนวน layer):

  1. เริ่มต้น

    ตั้ง \(\Delta_{ij}^{[l]} := 0\) ทุกตัว

  2. วนทุกตัวอย่างฝึก \((x^{(k)}, y^{(k)})\) : Forward

    \(a^{[0]} = x\); คำนวณ \(z^{[l]} = \theta^{[l]}a^{[l-1]},\ a^{[l]} = g(z^{[l]})\) ไปจนถึง \(a^{[L]}\)

  3. Error ที่ output
    $$\delta^{[L]} = a^{[L]} - y$$
  4. ส่งย้อนกลับ \(l = L, L-1, \dots, 2\)
    $$\delta^{[l-1]} = \left(\theta^{[l]\top}\delta^{[l]}\right)\odot g'\!\left(z^{[l-1]}\right)$$
  5. สะสม
    $$\Delta_{ij}^{[l]} \mathrel{+}= a_j^{[l-1]}\,\delta_i^{[l]}$$
  6. หลังครบทุกตัวอย่าง: เฉลี่ยแล้วอัปเดต
    $$D_{ij}^{[l]} = \frac{1}{m}\Delta_{ij}^{[l]},\qquad \theta_{ij}^{[l]} := \theta_{ij}^{[l]} - \alpha\,D_{ij}^{[l]}$$

ตัวอย่างใน §3 คือการรันอัลกอริทึมนี้ตรงๆ 1 รอบด้วย \(m=2\).

5. Activation Function และอนุพันธ์: ตัวเลือกที่ส่งผลต่อ Gradient

ตัวคูณ \(g'(z)\) อยู่ในสูตร \(\delta\) ทุก layer — ดังนั้น "รูปร่างของอนุพันธ์" ของ activation กำหนดว่า gradient ไหลย้อนกลับได้ไกลแค่ไหน.

5.1 Sigmoid

พิสูจน์ \(\sigma'(z) = \sigma(z)\big(1-\sigma(z)\big)\) (ตามสไลด์หน้า 25)
  1. เขียน \(\sigma\) เป็นเศษส่วน แล้วหาอนุพันธ์ด้วย quotient rule
    $$\sigma(z) = \frac{1}{1+e^{-z}}\ \Rightarrow\ \sigma'(z) = \frac{(1+e^{-z})\cdot 0 - 1\cdot(-e^{-z})}{(1+e^{-z})^2} = \frac{e^{-z}}{(1+e^{-z})^2}$$
  2. แยกเป็นผลคูณของสองเศษส่วน
    $$\frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}} = \sigma(z)\cdot\frac{e^{-z}}{1+e^{-z}}$$
  3. ทำเศษส่วนที่สองให้เป็น \(1-\sigma\)
    $$\frac{e^{-z}}{1+e^{-z}} = \frac{(1+e^{-z}) - 1}{1+e^{-z}} = 1 - \frac{1}{1+e^{-z}} = 1-\sigma(z)$$
$$\sigma'(z) = \sigma(z)\big(1-\sigma(z)\big)$$

อนุพันธ์ของ sigmoid มีค่าสูงสุดเพียง 0.25 ที่ \(z=0\) และหดเร็วเมื่อ \(|z|\) โต (ที่ \(z=\pm2\) เหลือ 0.105 — ต่ำกว่าครึ่งของยอดแล้ว). ถ้า sigmoid ต่อกัน \(L\) layer gradient จะถูกคูณด้วยตัวเลข \(\le0.25\) ซ้ำ \(L\) ครั้ง — เช่น 10 layer ⇒ \(0.25^{10}\approx10^{-6}\) นี่คือรากของ vanishing gradient (Lesson 5).

5.2 Tanh, ReLU และ Leaky ReLU

อนุพันธ์ของ tanh (สไลด์หน้า 26)
  1. นิยาม
    $$\tanh z = \frac{e^z - e^{-z}}{e^z + e^{-z}}\quad(\text{ช่วง }(-1,1),\ \tanh 0 = 0)$$
  2. อนุพันธ์ (ผลจากสไลด์)
    $$\frac{d}{dz}\tanh z = 1 - \tanh^2 z$$
  3. ค่าตัวอย่าง
    $$z=0:\ 1-0=1,\qquad z=2:\ 1-0.964^2 = 0.071,\qquad z=4:\ 0.0013$$

ยอด 1 (สูงกว่า sigmoid 4 เท่า) แต่ยัง saturate ที่ \(|z|\) ใหญ่เหมือนกัน; และ output อยู่รอบ 0 (ต่าง sigmoid ที่อยู่ [0,1]).

ReLU \(f(z) = \max(0, z)\) มีอนุพันธ์เป็น 0 หรือ 1 เท่านั้น:

$$f'(z) = \begin{cases}1 & z > 0\\ 0 & z < 0\end{cases}$$

เมื่อ \(z\ge0\) อนุพันธ์คงที่ 1 พอดี ⇒ ไม่ทำให้ gradient หดเลยไม่ว่าจะผ่านกี่ layer (คูณ 1 กี่ครั้งก็ยังเป็น 1) — เหตุผลหลักที่ ReLU เป็น default ของ hidden layer. ข้อเสีย: เมื่อ \(z<0\) อนุพันธ์เป็น 0 (node "ตาย" ถ้าติดโซนนี้ถาวร) จึงมี Leaky ReLU (สไลด์หน้า 31) ที่ให้ความชันเล็กน้อยแทน 0:

$$\text{Leaky ReLU: } f(z) = \max(0.01z,\ z),\qquad f'(z)=\begin{cases}1 & z>0\\ 0.01 & z<0\end{cases}$$

5.3 ทำไม activation ต้อง non-linear

สไลด์พิสูจน์โดยลองใช้ \(f(x)=x\) (linear) ทุก node — \(a = f(z) = z\) ไม่เปลี่ยนอะไรเลย:

พิสูจน์: linear ซ้อน linear ยังเป็น linear
ตัวอย่างตัวเลข 1 input: layer 1 \(z^{[1]} = 2x + 1\); layer 2 \(z^{[2]} = 3a^{[1]} - 4\)
  1. activation เป็น linear: \(a^{[1]} = z^{[1]}\)
    $$a^{[1]} = 2x + 1$$
  2. แทนเข้า layer 2
    $$z^{[2]} = 3(2x+1) - 4 = 6x + 3 - 4 = 6x - 1$$

ได้ \(6x-1\) = ฟังก์ชันเชิงเส้นของ \(x\) ตัวเดียว (สไลด์ใช้รูป \(a + bx_1 + cx_2\)) — 2 layer ยุบเหลือ layer เดียว. ถ้ามี 3, 10, 100 layer ก็ยุบเหลือ layer เดียวเสมอ เพราะ "linear ซ้อน linear = linear".

6. Output Layer และ Softmax: ต่อจาก Lesson 1

สูตร Softmax (Lesson 1 §8) เมื่อใช้เป็น activation ของ output layer: ตั้ง \(t_i = e^{z_i^{[L]}}\) แล้ว

$$a_i^{[L]} = \frac{t_i}{\sum_{n} t_n}$$

ต่างจาก sigmoid/ReLU ตรงที่ softmax เป็น activation ของทั้ง output layer พร้อมกัน (ต้องรู้ \(z\) ของทุก node ก่อนหารด้วยผลรวม) เพราะเป้าหมายคือความน่าจะเป็นของคลาสที่ "รวมกันได้ 1". และเมื่อใช้คู่กับ cross-entropy สูตร \(\delta^{[L]} = a^{[L]} - y\) จาก §2 ใช้ได้เหมือนเดิม.

7. Regularization และ Hyperparameter Tuning

L2 regularization ใน NN เพิ่ม penalty เข้า cost เหมือน Lesson 1 §11 แต่ผลรวมต้องไล่ 3 ระดับ (layer \(l\), node ปลายทาง \(i\), node ต้นทาง \(j\)):

(สไลด์หน้า 42 ยังแสดง L1 / Lasso ที่ใช้ค่าสัมบูรณ์ \(\frac{\lambda}{m}\sum|\theta_{ij}^{[l]}|\) แทนกำลังสอง แต่หน้า 43 ระบุว่า L1 อาจทำงานไม่นิ่งเมื่อ feature สัมพันธ์กันมากและไม่เหมาะกับ gradient descent จึงเน้น L2.) gradient ที่ใช้อัปเดต (สไลด์หน้า 43) บวกเทอม \(\dfrac{\lambda}{m}\theta\) เข้าไปสำหรับพารามิเตอร์ที่ไม่ใช่ bias:

$$D_{ij}^{[l]} = \frac{1}{m}\Delta_{ij}^{[l]} + \frac{\lambda}{m}\theta_{ij}^{[l]}\quad(j\ge1),\qquad D_{i0}^{[l]} = \frac{1}{m}\Delta_{i0}^{[l]}$$

NN มีพารามิเตอร์กระจายหลาย layer พร้อมกัน (ไม่ใช่ \(\theta\) ก้อนเดียวแบบ logistic regression) การบีบให้เล็กจึงต้องรวมทุกตัวทุก layer ใน penalty เดียว.
เปลี่ยนแล้วเกิดอะไร
เพิ่ม hidden layer อีก 1 ชั้น (2→10→10→1): \(\theta^{[1]}:10\times3=30\), \(\theta^{[2]}:10\times11=110\), \(\theta^{[3]}:1\times11=11\) รวม \(151\) — จาก 41 เป็น 151 (เกือบ 4 เท่า) ทั้งที่ hidden node รวมเพิ่มแค่เท่าตัว (10→20) เพราะ layer กลางเชื่อมกัน \(10\times10 = 100\) เส้น ไม่ใช่ \(10+10\).
เชื่อมกับ
เหตุผลที่ Lesson 4 §2 บอกว่า deep network เสี่ยง overfit กว่า wide network ที่พารามิเตอร์เท่ากัน — "ลึกขึ้น" ทำให้พารามิเตอร์ระเบิดเร็วกว่า "กว้างขึ้น".

ข้อควรจำจากสไลด์หน้า 42: เทอม regularization บวกเข้า cost ตอนเทรนเท่านั้น — เมื่อเทรนเสร็จให้ประเมินโมเดลด้วยตัววัดที่ไม่รวมเทอมนี้ (ไม่งั้นค่า error ที่ได้จะปนค่าปรับ ไม่ใช่ความผิดพลาดของการทำนายจริง). หมายเหตุหน้า 43: บางตำราหาร cost ด้วย 2 (\(\frac{1}{2m}\)) ทำให้ gradient ของเทอมปรับเหลือ \(\frac{\lambda}{m}\theta\) พอดี — สไลด์ใช้รูปนี้ต่อไป.

สไลด์หน้า 44–46 สรุปเชิงปฏิบัติ: parameter = ตัวที่โมเดลเรียนเอง (\(\theta\)) ส่วน hyperparameter = ตัวที่เราตั้ง (จำนวน layer/node, \(\alpha\), \(\lambda\), จำนวนรอบ) และเลือกด้วย validation set (Lesson 1 §9). การเลือกจำนวน layer/node ทำได้โดยเริ่มที่ขนาดปานกลางแล้วดูอาการ bias/variance (Lesson 1 §10).

8. Binary Classification Exercise: ฝึกเขียนสูตรทั่วไปซ้ำ

สไลด์ทิ้งแบบฝึกหัด 2 หน้า (forward + backward) กับ shallow NN input 2 node, hidden 10 node, output 1 node โดยไม่ให้ค่า \(\theta\) จริง — เป้าหมายคือฝึกเขียนสูตรทั่วไปเอง.

เฉลยสูตร (\(j = 1,\dots,10\))
  1. Forward: hidden layer
    $$z_j^{[1]} = \theta_{j0}^{[1]} + \theta_{j1}^{[1]}x_1 + \theta_{j2}^{[1]}x_2,\qquad a_j^{[1]} = g\!\left(z_j^{[1]}\right)$$
  2. Forward: output (ผลรวมยาว 10 พจน์)
    $$z_1^{[2]} = \theta_{10}^{[2]} + \sum_{j=1}^{10}\theta_{1j}^{[2]}a_j^{[1]},\qquad h(x) = a_1^{[2]} = g\!\left(z_1^{[2]}\right)$$
  3. Backward: output
    $$\delta_1^{[2]} = h(x) - y$$
  4. Backward: hidden
    $$\delta_j^{[1]} = \theta_{1j}^{[2]}\,\delta_1^{[2]}\,g'\!\left(z_j^{[1]}\right)$$
  5. Gradient
    $$\frac{\partial J}{\partial\theta_{1j}^{[2]}} = \delta_1^{[2]}a_j^{[1]},\qquad \frac{\partial J}{\partial\theta_{ji}^{[1]}} = \delta_j^{[1]}x_i$$

รูปเดียวกับตัวอย่าง §3 ทุกตัวอักษร แค่ \(j\) วิ่งถึง 10 แทน 2.

กลไกที่ต้องอธิบายได้
ทำไมต้องมี
backprop เป็น local operation: แต่ละ node คำนวณ \(\delta\) ของตัวเองจากแค่ \(\delta\) ของ node ที่มันเชื่อมโดยตรงใน layer ถัดไป ไม่ต้องรู้ว่าเครือข่ายมีกี่ node — จึงมีรูปสูตรเดียวกันไม่ว่า hidden 3 หรือ 10 หรือ 100 node.
เปลี่ยนแล้วเกิดอะไร
hidden 100 node แทน 10: สูตร \(\delta_j^{[1]}=\theta_{1j}^{[2]}\delta_1^{[2]}g'(z_j^{[1]})\) ไม่เปลี่ยนเลย สิ่งที่เปลี่ยนคือ "จำนวนครั้ง" ที่รันสูตร (100 ครั้ง) และขนาดเมทริกซ์ (\(\theta^{[1]}\): \(100\times3\), \(\theta^{[2]}\): \(1\times101\)).
เชื่อมกับ
เหตุผลที่ backprop สเกลไปโมเดลพารามิเตอร์พันล้านตัวได้ (LLM ใน timeline ของ Lesson 1) — ถ้าต้องมีสูตรพิเศษต่อขนาด จะเขียนเป็นโค้ดทั่วไปไม่ได้.

คำถาม 10Why Non-linear
ถ้าทุก node ในเครือข่ายใช้ activation function แบบ linear (f(x)=x) ไม่ว่าจะมีกี่ layer ผลลัพธ์สุดท้ายของเครือข่ายจะเป็นอย่างไร?

ชัยชนะของบทเรียนนี้
คุณควรพิสูจน์สูตร \(\delta^{[L]}=a^{[L]}-y\) และ \(\delta^{[l-1]}=(\theta^{[l]\top}\delta^{[l]})\odot g'(z^{[l-1]})\) ได้ด้วย chain rule เอง, รันตัวอย่างเต็ม 2 layer 2 examples ได้มือ (forward → \(\delta\) → \(\Delta\) → \(D\) → update \(\theta\) พร้อมตรวจว่า cost ลด), พิสูจน์ \(\sigma'=\sigma(1-\sigma)\) และเปรียบเทียบ activation ต่างๆ ผ่านค่าอนุพันธ์, อธิบายได้ว่าทำไมต้อง non-linear activation, และนับพารามิเตอร์ของโครงข่ายใดๆ ได้ — สูตรเดียวที่ Lesson 4 จะขยายจาก 2 layer เป็น \(L\) layer.
