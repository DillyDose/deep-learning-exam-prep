แบบฝึก Lesson 13: Autoencoder, VAE และ GAN

ข้อเลือกตอบ 15 ข้อ กดแล้วเห็นผลและเหตุผลของทุกตัวเลือกทันที ข้อคำนวณทุกข้อทำได้ด้วยมือโดยไม่ใช้เครื่องคิดเลข ส่วนข้อเขียน 3 ข้อให้ลองเขียนก่อนแล้วจึงกดดูเฉลย

ข้อเลือกตอบ

ข้อ 1Conv2D shape
Encoder รับรูป (28, 28, 1) แล้วผ่าน Conv2D(32, 3, strides=2, padding="same") output shape และจำนวน parameter คือข้อใด
ข้อ 2Dense ใน encoder
หลัง Flatten ได้ vector ยาว 3136 แล้วต่อ Dense(latent_dim) โดย latent_dim = 2 layer นี้มี parameter กี่ตัว
ข้อ 3Conv2DTranspose
Conv2DTranspose(64, 3, strides=2, padding="same") รับ input (7, 7, 64) output shape และ parameter คือข้อใด
ข้อ 4ปัญหาของ autoencoder
ทำไม autoencoder ธรรมดาที่ reconstruct รูปได้ดีจึงยังไม่เหมาะจะใช้สร้างรูปใหม่ด้วยการสุ่มจุดใน latent space
ข้อ 5Sampling z
Encoder ของ VAE ให้ค่าสำหรับมิติหนึ่งของ latent คือ z_mean = 1.0 และ z_log_var = 0 ถ้าสุ่มได้ ε = −0.5 ค่า z ที่ Sampling layer คืนออกมาคือเท่าใด
ข้อ 6log variance
เหตุผลที่ encoder ของ VAE ส่งออก log σ² แทน σ² คือข้อใด
ข้อ 7KL ต่อมิติ
latent loss ต่อมิติคือ ½(σ² + μ² − 1 − log σ²) ถ้ามิติหนึ่งมี μ = 2 และ σ = 1 latent loss ของมิตินี้เท่ากับเท่าใด
ข้อ 8KL ดันไปทางไหน
ถ้าให้น้ำหนัก KL divergence มากและ reconstruction น้อย (β-VAE ที่ β ใหญ่) ผลที่คาดได้คือข้อใด
ข้อ 9Discriminator param
Discriminator รับ tensor (16, 16, 64) เข้า Conv2D(128, kernel_size=4, strides=2, padding="same") layer นี้มี parameter กี่ตัว
ข้อ 10ฝึก generator
ข้อใดอธิบายการฝึก generator ของ GAN ถูกต้อง
ข้อ 11label ในโค้ด GAN
ในโค้ด GAN ของคาบ รูปที่สร้างได้ label = ones และรูปจริงได้ label = zeros ขั้นฝึก generator ใช้ misleading_labels = ops.zeros((batch_size, 1)) เพราะอะไร
ข้อ 12mode collapse
Generator สร้างรูปหน้าคนออกมาไม่กี่แบบที่เกือบเหมือนกันทุกครั้ง แต่ยังหลอก discriminator ได้ อาการนี้คืออะไรและเกิดจากอะไร
ข้อ 13วัดผล GAN
ข้อใดถูกต้องเรื่องการวัดคุณภาพรูปจาก GAN
ข้อ 14VAE เทียบ GAN
งานที่ต้องเปลี่ยนหน้าบึ้งให้ยิ้มทีละน้อยแบบต่อเนื่องในหลายเฟรม ควรเลือกโมเดลใดและเพราะอะไร
ข้อ 15Generator Dense
Generator รับ latent vector ขนาด 128 แล้วต่อ Dense(8 * 8 * 128) ก่อน Reshape เป็น (8, 8, 128) Dense นี้มี parameter กี่ตัว

ข้อเขียน

ข้อ 16reparameterization
อธิบายว่าทำไม VAE ต้องเขียนการสุ่มเป็น z = μ + σε แทนที่จะสุ่ม z จาก N(μ, σ²) ตรงๆ และ ε มาจากไหน

การสุ่มเป็นขั้นที่หา gradient ไม่ได้ ถ้าสุ่ม z ตรงๆ backpropagation จะส่ง gradient ผ่านจุดนั้นกลับไปหา μ และ σ ไม่ได้

เขียนใหม่ให้ความสุ่มอยู่ที่ ε ~ N(0, 1) ซึ่งมาจากนอกโมเดล ส่วน μ และ σ เป็นการคูณและบวกธรรมดาที่หาอนุพันธ์ได้ จึงปรับ weight ของ encoder ได้

ในโค้ด ε มาจาก keras.random.normal(shape=(batch, dim)) และ σ ได้จาก exp(0.5 · z_log_var)

ข้อ 176 ขั้นของ GAN
เขียนขั้นตอนการฝึก GAN หนึ่งรอบให้ครบ และระบุว่าขั้นไหนฝึก D ขั้นไหนฝึก G

1 สุ่ม noise 2 generator สร้างรูป 3 ผสมกับรูปจริง 4 ฝึก D ด้วย label จริงและปลอม (ขั้น 1–4 ฝึก D)

5 สุ่ม noise ชุดใหม่ 6 ฝึก G ผ่าน D ที่ freeze โดย label ทั้งหมดบอกว่าเป็นรูปจริง (ขั้น 5–6 ฝึก G)

ข้อ 18shape decoder
decoder ของ autoencoder: Input(2) → Dense(7*7*64) → Reshape((7,7,64)) → Conv2DTranspose(64,3,strides=2,"same") → Conv2DTranspose(32,3,strides=2,"same") → Conv2D(1,3,"same") เขียน output shape และ parameter ทุก layer พร้อมผลรวม

Dense: (3136), 2·3136 + 3136 = 9,408 · Reshape: (7, 7, 64), 0

Conv2DTranspose 64: (14, 14, 64), (3·3·64 + 1)·64 = 36,928

Conv2DTranspose 32: (28, 28, 32), (3·3·64 + 1)·32 = 18,464

Conv2D 1: (28, 28, 1), (3·3·32 + 1)·1 = 289 · รวม 65,089
