ข้อ 25parameter ของโมเดล recurrent
input (None, 30, 5) → GRU(8, return_sequences=True) → LSTM(4) → Dense(1) ใช้สูตรตามสไลด์ คือ GRU 3 ชุด LSTM 4 ชุด bias ชุดเดียว เขียน parameter ทุกชั้นและ output shape

GRU: หนึ่งชุด 8 × (8 + 5) + 8 = 112 · สามชุด 336 · output (None, 30, 8) เพราะ return_sequences=True

LSTM: m = 8 จากชั้นก่อน หนึ่งชุด 4 × (4 + 8) + 4 = 52 · สี่ชุด 208 · output (None, 4)

Dense(1): 4 + 1 = 5 · รวม 549 · ถ้าใช้ GRU ของ Keras ที่มี bias สองชุดจะได้ 3 × (112 + 8) = 360

ข้อ 26ไล่ GRU ด้วยมือ
GRU แบบ simplified memory เริ่ม c⟨0⟩ = 0 ค่าเสนอ c̃ ของสาม step คือ 0.8, −0.4, 0.6 และ Γ_u คือ 1, 0, 0.5 คำนวณ c ทุก step และบอกว่า step ไหน memory ถูกคัดลอกเฉยๆ

step 1: 1 × 0.8 + 0 × 0 = 0.8

step 2: Γ_u = 0 จึง 0 × (−0.4) + 1 × 0.8 = 0.8 คือคัดลอกค่าเดิม ค่าเสนอ −0.4 ถูกละทิ้ง

step 3: 0.5 × 0.6 + 0.5 × 0.8 = 0.7

ข้อ 27one-hot กับ embedding
vocabulary 50,000 คำ ประโยคยาว 12 คำ เทียบ one-hot กับ Embedding(input_dim=50000, output_dim=100) ในแง่จำนวนค่าที่ป้อนเข้า layer ถัดไป จำนวน parameter และความสามารถบอกว่าคำสองคำคล้ายกัน

one-hot: 12 × 50,000 = 600,000 ค่าต่อประโยค ไม่มี parameter ให้เรียน dot product ของคำต่างกันเป็น 0 ทุกคู่ จึงบอกความคล้ายไม่ได้

Embedding: 12 × 100 = 1,200 ค่าต่อประโยค มี parameter 50,000 × 100 = 5,000,000 ที่เรียนจากข้อมูล

embedding วางคำความหมายใกล้กันไว้ใกล้กัน และทิศใน vector space แทนความสัมพันธ์ เช่น Dog → Wolf ขนานกับ Cat → Tiger
